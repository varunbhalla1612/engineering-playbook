## 1. Two Sum

### Pattern

Hash Map + Complement Lookup

### Recognize

* Find two numbers that add to a target
* Return the indices
* Need better than `O(n²)`
* Pair-sum problem

### Idea

For every number, calculate the value needed to reach the target:

```text
complement = target - current
```

Check whether the complement was already seen. If it was, return its stored index and the current index.

Otherwise, store the current number and index.

### Code

```python
class Solution(object):
    def twoSum(self, nums, target):
        seen = {}

        for index, value in enumerate(nums):
            complement = target - value

            if complement in seen:
                return [seen[complement], index]

            seen[value] = index
```

### Remember

* Time: `O(n)`
* Space: `O(n)`
* Store `value → index`
* Check before inserting the current value
* Duplicates can form the answer

> For every number, ask: “Have I already seen the number I need?”

## 217. Contains Duplicate

### Pattern

Hash Set

### Recognize

* Check whether any value appears more than once
* Detect duplicates
* Only need `True` or `False`
* Need faster than comparing every pair

### Idea

Use a set to store values that have already been seen.

For every number:

* If it is already in the set, a duplicate exists.
* Otherwise, add it to the set.

### Code

```python
class Solution(object):
    def containsDuplicate(self, nums):
        seen = set()

        for number in nums:
            if number in seen:
                return True

            seen.add(number)

        return False
```

### Remember

* Time: `O(n)`
* Space: `O(n)`
* A set stores unique values
* Set lookup is approximately `O(1)`
* Return immediately after finding a duplicate

> Seen before means duplicate.

## 242. Valid Anagram

### Pattern

Frequency Counting

### Recognize

* Compare two strings
* Same characters
* Same number of occurrences
* Character order does not matter
* Rearrangement or permutation

### Idea

Anagrams are determined by character frequencies, not character positions.

Count characters from the first string and subtract characters from the second string.

If the lengths differ or a count becomes invalid, the strings are not anagrams.

### Code

```python
class Solution(object):
    def isAnagram(self, s, t):
        if len(s) != len(t):
            return False

        frequency = {}

        for character in s:
            frequency[character] = frequency.get(character, 0) + 1

        for character in t:
            if character not in frequency:
                return False

            frequency[character] -= 1

            if frequency[character] < 0:
                return False

        return True
```

### Remember

* Time: `O(n)`
* Space: `O(k)`
* `k` is the number of unique characters
* Check the string lengths first
* Character existence alone is not enough; frequency matters

> Order does not matter, so compare counts.

## 49. Group Anagrams

### Pattern

Hash Map + Frequency Signature

### Recognize

* Group strings by similarity
* Words are anagrams
* Same characters with the same frequencies
* Return groups instead of `True` or `False`
* Input contains lowercase English letters

### Idea

Every group of anagrams has the same character-frequency signature.

For every word:

1. Create a frequency array of length 26.
2. Count the letters in the word.
3. Convert the list into a tuple.
4. Use the tuple as a dictionary key.
5. Add the word to that group.

### Code

```python
from collections import defaultdict


class Solution(object):
    def groupAnagrams(self, strs):
        groups = defaultdict(list)

        for word in strs:
            count = [0] * 26

            for character in word:
                index = ord(character) - ord("a")
                count[index] += 1

            signature = tuple(count)
            groups[signature].append(word)

        return list(groups.values())
```

### Remember

* Time: `O(n × k)`
* Space: `O(n × k)`
* `n` is the number of words
* `k` is the maximum word length
* Lists cannot be dictionary keys
* Tuples can be dictionary keys
* `ord(character) - ord("a")` maps letters to indices `0–25`
* Create a new count array for every word

> Give every word a fingerprint, then group matching fingerprints.

## 347. Top K Frequent Elements

### Pattern

Frequency Counting + Bucket Sort

### Recognize

* Find the most frequent elements
* Return the top `k`
* Rank numbers by frequency
* Follow-up requires better than `O(n log n)`
* A frequency cannot exceed the input length

### Idea

First, count the frequency of every number.

Then create buckets where:

```text
bucket index = frequency
```

For example:

```text
buckets[3] = numbers that appear 3 times
```

Scan the buckets backward from the highest frequency and collect numbers until the result contains `k` elements.

### Code

#### Bucket Sort — `O(n)`

```python
from collections import Counter


class Solution(object):
    def topKFrequent(self, nums, k):
        counter = Counter(nums)

        buckets = [[] for _ in range(len(nums) + 1)]

        for number, frequency in counter.items():
            buckets[frequency].append(number)

        result = []

        for frequency in range(len(buckets) - 1, 0, -1):
            for number in buckets[frequency]:
                result.append(number)

                if len(result) == k:
                    return result
```

#### Heap Method

```python
from collections import Counter
from heapq import heappush, heappop


class Solution(object):
    def topKFrequent(self, nums, k):
        counter = Counter(nums)
        heap = []

        for number, frequency in counter.items():
            heappush(heap, (-frequency, number))

        result = []

        for _ in range(k):
            frequency, number = heappop(heap)
            result.append(number)

        return result
```

### Remember

#### Bucket Sort

* Time: `O(n)`
* Space: `O(n)`
* Create `len(nums) + 1` buckets
* Bucket index represents frequency
* Scan from high frequency to low frequency
* This satisfies the follow-up requirement

#### Heap

* Use `(-frequency, number)` because Python has a min-heap
* Negative frequency makes the most frequent value come out first
* Adding all unique values individually can take `O(n log n)` in the worst case
* The heap solution is correct, but bucket sort is better for the follow-up

> Count first, then use frequency as the bucket index.
