## 1. Two Sum

**Goal:** Return the indices of two numbers whose sum equals `target`.

### Example Trace

```text
nums = [2, 7, 11, 15]
target = 9

Start:
seen = {}

Current = 2
Needed = 9 - 2 = 7
7 is not in seen
Store 2 → index 0

seen = {2: 0}

Current = 7
Needed = 9 - 7 = 2
2 is already in seen at index 0

Return [0, 1]
```

### Rebuild the Solution

```text
For every number:

1. Calculate needed = target - current number.
2. Check whether needed is already in the hash map.
3. If yes, return its index and the current index.
4. Otherwise, store current number → current index.
```

### Code

```python
class Solution(object):
    def twoSum(self, nums, target):
        seen = {}

        for index, number in enumerate(nums):
            needed = target - number

            if needed in seen:
                return [seen[needed], index]

            seen[number] = index
```

### Complexity

```text
Time:  O(n)
Space: O(n)
```

## 217. Contains Duplicate

**Goal:** Return `True` if any number appears more than once.

### Example Trace

```text
nums = [1, 2, 3, 1]

Start:
seen = {}

Current = 1
1 is not in seen
Add 1

seen = {1}

Current = 2
2 is not in seen
Add 2

seen = {1, 2}

Current = 3
3 is not in seen
Add 3

seen = {1, 2, 3}

Current = 1
1 is already in seen

Return True
```

### Rebuild the Solution

```text
For every number:

1. Check whether the number is already in the set.
2. If yes, return True.
3. Otherwise, add it to the set.
4. If the loop finishes, return False.
```

### Code

```python
class Solution(object):
    def containsDuplicate(self, nums):
        seen = set()

        for number in nums:
            if number in seen:
                return True

            seen.add(number)

        return False
```

### Complexity

```text
Time:  O(n)
Space: O(n)
```

## 242. Valid Anagram

**Goal:** Check whether two strings contain exactly the same characters with the same frequencies.

### Example Trace

```text
s = "anagram"
t = "nagaram"
```

Count the characters in `s`:

```text
a → 3
n → 1
g → 1
r → 1
m → 1
```

Subtract using the characters in `t`:

```text
n: 1 → 0
a: 3 → 2
g: 1 → 0
a: 2 → 1
r: 1 → 0
a: 1 → 0
m: 1 → 0
```

All counts return to zero:

```text
Return True
```

### Rebuild the Solution

```text
1. If the string lengths are different, return False.
2. Count every character in the first string.
3. Go through the second string and subtract each character.
4. If a character is missing or its count becomes negative, return False.
5. Otherwise, return True.
```

### Code

```python
class Solution(object):
    def isAnagram(self, s, t):
        if len(s) != len(t):
            return False

        frequency = {}

        for character in s:
            frequency[character] = frequency.get(character, 0) + 1

        for character in t:
            if character not in frequency:
                return False

            frequency[character] -= 1

            if frequency[character] < 0:
                return False

        return True
```

### Complexity

```text
Time:  O(n)
Space: O(k)
```

```text
k = number of unique characters
```

## 49. Group Anagrams

**Goal:** Group words that contain the same characters with the same frequencies.

### Example Trace

```text
words = ["eat", "tea", "tan", "ate", "nat", "bat"]
```

Create a character-count fingerprint for each word.

For `"eat"`:

```text
a → 1
e → 1
t → 1
```

For `"tea"`:

```text
a → 1
e → 1
t → 1
```

For `"ate"`:

```text
a → 1
e → 1
t → 1
```

All three words have the same fingerprint:

```text
["eat", "tea", "ate"]
```

For `"tan"`:

```text
a → 1
n → 1
t → 1
```

For `"nat"`:

```text
a → 1
n → 1
t → 1
```

These words form another group:

```text
["tan", "nat"]
```

Final result:

```text
[
    ["eat", "tea", "ate"],
    ["tan", "nat"],
    ["bat"]
]
```

### Rebuild the Solution

```text
For every word:

1. Create a fresh array of 26 zeros.
2. Count each letter using ord(character) - ord("a").
3. Convert the count list into a tuple.
4. Use the tuple as the dictionary key.
5. Append the word to that key's list.
6. Return all the dictionary values.
```

### Code

```python
from collections import defaultdict


class Solution(object):
    def groupAnagrams(self, strs):
        groups = defaultdict(list)

        for word in strs:
            count = [0] * 26

            for character in word:
                index = ord(character) - ord("a")
                count[index] += 1

            fingerprint = tuple(count)
            groups[fingerprint].append(word)

        return list(groups.values())
```

### Why Use a Tuple?

```text
List:
[1, 0, 2]
Cannot be used as a dictionary key.

Tuple:
(1, 0, 2)
Can be used as a dictionary key.
```

### Complexity

```text
Time:  O(n × k)
Space: O(n × k)
```

```text
n = number of words
k = maximum word length
```

## 347. Top K Frequent Elements

**Goal:** Return the `k` numbers that appear most frequently.

### Example Trace

```text
nums = [1, 1, 1, 2, 2, 3]
k = 2
```

Count each number:

```text
1 → 3 times
2 → 2 times
3 → 1 time
```

---

### Method 1: Heap

Put this tuple into the heap:

```text
(-frequency, number)
```

The heap receives:

```text
(-3, 1)
(-2, 2)
(-1, 3)
```

Python uses a min-heap.

Because:

```text
-3 < -2 < -1
```

the number with the highest real frequency is removed first.

Pop `k = 2` times:

```text
Pop (-3, 1) → add 1
Pop (-2, 2) → add 2
```

Return:

```text
[1, 2]
```

### Rebuild the Heap Solution

```text
1. Count every number.
2. Push (-frequency, number) into the heap.
3. Pop from the heap k times.
4. Add the number from each tuple to the result.
```

### Heap Code

```python
from collections import Counter
from heapq import heappush, heappop


class Solution(object):
    def topKFrequent(self, nums, k):
        counter = Counter(nums)
        heap = []

        for number, frequency in counter.items():
            heappush(heap, (-frequency, number))

        result = []

        for _ in range(k):
            frequency, number = heappop(heap)
            result.append(number)

        return result
```

### Heap Complexity

```text
Time:  O(n + m log m)
Space: O(m)
```

```text
m = number of unique values
```

In the worst case, `m = n`, so the time can become:

```text
O(n log n)
```

This method is correct, but it does not satisfy the strict follow-up requiring better than `O(n log n)`.

---

### Method 2: Bucket Sort

Use the frequency as the bucket index.

The counts are:

```text
1 → 3 times
2 → 2 times
3 → 1 time
```

Place each number into its frequency bucket:

```text
bucket[1] = [3]
bucket[2] = [2]
bucket[3] = [1]
```

The full bucket list looks like:

```text
[
    [],     # frequency 0
    [3],    # frequency 1
    [2],    # frequency 2
    [1],    # frequency 3
    [],
    [],
    []
]
```

Scan from the end because the highest frequencies are on the right:

```text
bucket[3] → add 1
bucket[2] → add 2
```

The result now contains `k = 2` values:

```text
[1, 2]
```

### Rebuild the Bucket Solution

```text
1. Count every number.
2. Create len(nums) + 1 empty buckets.
3. Put each number into buckets[frequency].
4. Scan the buckets from right to left.
5. Add numbers to the result.
6. Return when the result contains k numbers.
```

### Bucket Sort Code

```python
from collections import Counter


class Solution(object):
    def topKFrequent(self, nums, k):
        counter = Counter(nums)

        buckets = [[] for _ in range(len(nums) + 1)]

        for number, frequency in counter.items():
            buckets[frequency].append(number)

        result = []

        for frequency in range(len(buckets) - 1, 0, -1):
            for number in buckets[frequency]:
                result.append(number)

                if len(result) == k:
                    return result
```

### Why `len(nums) + 1`?

Suppose:

```text
nums = [5, 5, 5]
```

The number `5` has frequency `3`.

We need:

```text
buckets[3]
```

A list of length `3` only has indices:

```text
0, 1, 2
```

A list of length `4` has indices:

```text
0, 1, 2, 3
```

Therefore:

```python
buckets = [[] for _ in range(len(nums) + 1)]
```

### Bucket Sort Complexity

```text
Time:  O(n)
Space: O(n)
```

This method satisfies the follow-up requiring better than `O(n log n)`.
