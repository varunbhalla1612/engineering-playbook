|  1 | **Two Sum**<br>LeetCode #1                   | **Pattern:** Hash Map + Complement Lookup<br><br>**Recognize:**<br>• Find a pair of numbers<br>• `a + b = target`<br>• Return indices<br>• Need `O(n)`                                                     | For every number, calculate the value needed to reach the target:<br><br>`complement = target - current`<br><br>If the complement was already seen, return its stored index and the current index. Otherwise, store the current value and index.<br><br>**Steps:**<br>1. Create `seen = {}`<br>2. Calculate complement<br>3. Check map<br>4. Store current value                                                                     | `seen = {}`<br><br>`for i, value in enumerate(nums):`<br>  `complement = target - value`<br>  `if complement in seen:`<br>    `return [seen[complement], i]`<br>  `seen[value] = i`                                                                                                                                                                                                                                                                                                                                                                                                                                                       | **Time:** `O(n)`<br>**Space:** `O(n)`                                                                                                                             | **Mistakes:**<br>• Using nested loops: `O(n²)`<br>• Storing values instead of indices<br>• Storing before checking<br>• Forgetting duplicates<br><br>**Memory Hook:**<br>“Have I already seen the number I need?”                                                                                                            |
|  2 | **Valid Anagram**<br>LeetCode #242           | **Pattern:** Frequency Counting<br><br>**Recognize:**<br>• Same characters<br>• Same occurrences<br>• Order does not matter<br>• Rearrangement or permutation                                              | Anagrams are determined by character frequencies, not character positions.<br><br>Count characters in the first string and subtract using the second string. Every final count must be zero.<br><br>**Steps:**<br>1. Compare lengths<br>2. Count characters in `s`<br>3. Subtract characters in `t`<br>4. Verify counts                                                                                                              | `if len(s) != len(t):`<br>  `return False`<br><br>`freq = {}`<br><br>`for ch in s:`<br>  `freq[ch] = freq.get(ch, 0) + 1`<br><br>`for ch in t:`<br>  `if ch not in freq:`<br>    `return False`<br>  `freq[ch] -= 1`<br>  `if freq[ch] < 0:`<br>    `return False`<br><br>`return True`                                                                                                                                                                                                                                                                                                                                                   | **Time:** `O(n)`<br>**Space:** `O(k)`<br><br>`k` = number of unique characters.<br>For a fixed alphabet, space is `O(1)`.                                         | **Mistakes:**<br>• Checking only character existence<br>• Forgetting length check<br>• Comparing order<br>• Ignoring duplicate counts<br><br>**Memory Hook:**<br>“Same items and order does not matter → count frequencies.”                                                                                                 |
|  3 | **Group Anagrams**<br>LeetCode #49           | **Pattern:** Hash Map + Frequency Signature<br><br>**Recognize:**<br>• Group similar strings<br>• Words have identical character counts<br>• Return groups<br>• Lowercase English letters                  | Every anagram has the same frequency signature.<br><br>For each word, create a 26-element frequency array. Convert it to a tuple so it can be used as a dictionary key. Words with the same tuple belong to the same group.<br><br>**Steps:**<br>1. Create `defaultdict(list)`<br>2. Count letters<br>3. Convert list to tuple<br>4. Group by tuple                                                                                  | `groups = defaultdict(list)`<br><br>`for word in words:`<br>  `count = [0] * 26`<br><br>  `for ch in word:`<br>    `index = ord(ch) - ord('a')`<br>    `count[index] += 1`<br><br>  `groups[tuple(count)].append(word)`<br><br>`return list(groups.values())`                                                                                                                                                                                                                                                                                                                                                                             | **Time:** `O(n × k)`<br>**Space:** `O(n × k)`<br><br>`n` = number of words<br>`k` = maximum word length                                                           | **Mistakes:**<br>• Using a list as a dictionary key<br>• Forgetting `tuple(count)`<br>• Reusing the same count array<br>• Using 27 instead of 26<br>• Forgetting `groups.values()`<br><br>**Memory Hook:**<br>“Give every item a fingerprint, then group matching fingerprints.”                                             |
|  4 | **Top K Frequent Elements**<br>LeetCode #347 | **Pattern:** Frequency Counting + Heap or Bucket Sort<br><br>**Recognize:**<br>• Most frequent elements<br>• Return top `k`<br>• Rank by occurrence count<br>• Follow-up asks for better than `O(n log n)` | First count every number using `Counter`.<br><br>**Method 1 — Heap:**<br>Push `(-frequency, number)` into Python’s min-heap. Negative frequency makes high frequencies come out first.<br><br>**Method 2 — Bucket Sort:**<br>Use frequency as an array index:<br>`buckets[frequency] = numbers with that frequency`<br><br>Scan buckets backward to get the most frequent values.<br><br>Bucket sort satisfies the `O(n)` follow-up. | **Heap:**<br>`count = Counter(nums)`<br>`heap = []`<br><br>`for number, freq in count.items():`<br>  `heappush(heap, (-freq, number))`<br><br>`result = []`<br>`for _ in range(k):`<br>  `freq, number = heappop(heap)`<br>  `result.append(number)`<br><br>**Bucket Sort:**<br>`count = Counter(nums)`<br>`buckets = [[] for _ in range(len(nums) + 1)]`<br><br>`for number, freq in count.items():`<br>  `buckets[freq].append(number)`<br><br>`result = []`<br>`for freq in range(len(buckets) - 1, 0, -1):`<br>  `for number in buckets[freq]:`<br>    `result.append(number)`<br>    `if len(result) == k:`<br>      `return result` | **Heap:**<br>`O(n + m log m + k log m)`<br>Worst case: `O(n log n)`<br><br>**Bucket Sort:**<br>Time: `O(n)`<br>Space: `O(n)`<br><br>`m` = number of unique values | **Mistakes:**<br>• Thinking the full heap method is `O(n)`<br>• Forgetting negative frequencies<br>• Creating only `len(nums)` buckets instead of `len(nums) + 1`<br>• Scanning buckets forward<br>• Returning more than `k` values<br><br>**Memory Hook:**<br>“Count first. For `O(n)`, use frequency as the bucket index.” |
